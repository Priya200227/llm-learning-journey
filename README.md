## Overview

This repository is my working knowledge base for learning modern LLM application development. It brings together:

- **Concept notes** explaining key ideas and terminology
- **Python implementations** that turn concepts into working examples
- **Hands-on experiments** for testing approaches and observing results
- **Mini-projects** that combine multiple concepts into practical workflows
- **Learning resources** used to support further study
- **Technical observations** documenting lessons, trade-offs, and questions

The repository will evolve as I study new topics, revisit earlier concepts, and build more complete applications.

## Learning Objectives

The learning path is intended to develop understanding and practical ability in the following areas:

1. **LLM fundamentals** — understand the core concepts and architecture behind large language models.
2. **Prompt engineering** — learn how instructions and context influence model outputs.
3. **Embeddings and semantic search** — represent text for similarity-based retrieval.
4. **Vector databases** — explore how vector representations are stored and searched.
5. **Retrieval-Augmented Generation (RAG)** — connect retrieval with generation to ground responses in external information.
6. **LLM application frameworks** — learn where LangChain is useful and how it supports application workflows.
7. **Graph-based orchestration** — explore LangGraph for stateful, multi-step workflows.
8. **Tool calling and AI agents** — connect models to tools and build workflows that can take structured actions.
9. **Application development and deployment** — explore FastAPI and Docker as part of serving and packaging applications.
10. **Applied AI** — build AI-powered analytics applications and investigate business-oriented use cases.

## How to Use This Repository

For a useful study sequence:

1. Start with the fundamentals and build a working understanding of each concept.
2. Read the topic notes before reviewing the corresponding implementation.
3. Run code examples where available and inspect the inputs, outputs, and assumptions.
4. Record experiments, limitations, and lessons learned instead of documenting only successful results.
5. Use the projects to connect individual concepts into end-to-end workflows.

Examples and implementations may be refined as my understanding improves.

## Guiding Principles

- **Understand before abstracting:** learn the underlying problem a tool or framework is designed to solve.
- **Build alongside learning:** reinforce theory with runnable code and small experiments.
- **Evaluate trade-offs:** consider limitations, complexity, reliability, and maintainability—not just whether an example works.
- **Keep learning traceable:** organize notes and implementations by topic.
- **Work toward real use cases:** connect LLM techniques to practical applications, including analytics and business problems.

## Long-Term Objective

The long-term objective is to progress from understanding LLM concepts to designing, implementing, and evaluating practical AI applications. This includes retrieval-grounded systems, tool-enabled workflows, and AI-powered analytics solutions.
