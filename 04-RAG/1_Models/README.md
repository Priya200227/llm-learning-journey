# 🤖 Models

## Overview

This folder contains my practice code for understanding the different types of models used in LangChain and modern LLM applications.

I explored how language models generate text, how chat models handle conversations, and how embedding models convert text into numerical vectors for semantic search and Retrieval-Augmented Generation (RAG).

---

## Folder Structure

### 📂 1_LLMs

Basic examples of working with traditional Large Language Models (LLMs) using LangChain.

Topics covered:

- LLM initialization
- Model invocation
- Basic text generation

---

### 📂 2_ChatModels

Examples of chat-based language models from different providers.

Topics covered:

- OpenAI Chat Models
- Google Gemini
- Anthropic Claude
- Hugging Face Models
- Local Hugging Face Models

---

### 📂 3_EmbeddedModels

Practice examples for generating text embeddings and measuring semantic similarity.

Topics covered:

- OpenAI Embeddings
- Hugging Face Embeddings
- Query Embeddings
- Document Embeddings
- Semantic Similarity

---

## What I Learned

- The difference between LLMs, Chat Models, and Embedding Models.
- When to use each type of model in an AI application.
- How embedding models represent text as vectors.
- Why embeddings are the foundation of semantic search and Retrieval-Augmented Generation (RAG).
- How LangChain provides a unified interface for working with different model providers.
