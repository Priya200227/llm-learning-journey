# 🔢 Embedding Models

## Overview

This folder contains basic examples demonstrating how embedding models are used in LangChain.

The code covers generating embeddings for queries and documents, working with different embedding providers, and measuring semantic similarity between text.

### Files

- `1_embedding_openai_query.py` – Generate query embeddings using OpenAI
- `2_embedding_openai_docs.py` – Generate document embeddings
- `3_embedding_hf_local.py` – Local Hugging Face embedding model
- `4_document_similarity.py` – Calculate semantic similarity between documents

These examples helped me understand how text is converted into vector representations before performing semantic search and Retrieval-Augmented Generation (RAG).
