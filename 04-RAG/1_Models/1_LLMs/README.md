# 🤖 LLM Demo

## Overview

This folder contains a simple Python example demonstrating how to interact with a Large Language Model (LLM) using LangChain.

The code covers the basic workflow of:

- Loading environment variables
- Initializing an LLM
- Sending a prompt using `invoke()`
- Receiving and printing the model's response

This was my first hands-on implementation while learning how LangChain communicates with an LLM before moving on to Retrieval-Augmented Generation (RAG) concepts.

### Files

- `llm_demo.py` — Basic LangChain LLM example.
