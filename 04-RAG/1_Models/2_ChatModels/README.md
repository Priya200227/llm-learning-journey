# 💬 Chat Models

## Overview

This folder contains simple Python examples demonstrating how to use different chat models with LangChain.

The examples cover integrating multiple LLM providers and sending basic chat prompts using their respective APIs.

### Files

- `1_chatmodel_openai.py` – OpenAI Chat Model
- `2_chatmodel_anthropic.py` – Anthropic Claude Chat Model
- `3_chatmodel_google.py` – Google Gemini Chat Model
- `4_chatmodel_huggingface.py` – Hugging Face Inference API
- `5_chatmodel_hf_local.py` – Local Hugging Face Model

These examples helped me understand that LangChain provides a common interface for interacting with different chat model providers.
