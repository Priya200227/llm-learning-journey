# 💬 Prompt Templates

## Overview

This folder contains my practice code for understanding how prompts are created and managed in LangChain.

Instead of writing plain text prompts, LangChain provides reusable prompt templates that make it easier to build structured, dynamic, and maintainable LLM applications.

Through these examples, I explored how prompts are generated, formatted, reused, and combined with chat history before being sent to a language model.

---

## Files Included

- `chat_prompt_template.py` – Creating chat prompt templates
- `chatbot.py` – Basic chatbot implementation
- `messages.py` – Working with different message types
- `message_placeholder.py` – Using placeholders for conversation history
- `prompt_generator.py` – Generating dynamic prompts
- `prompt_ui.py` – Simple prompt interface
- `main.py` – Running the examples
- `chat_history.txt` – Sample conversation history
- `template.json` – Prompt template configuration
